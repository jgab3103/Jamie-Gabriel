Booking Enquiries

For solo performances, it is great if I can come and check out the venue beforehand, to make sure set up and sound is going to be great on the day. I find people often like particular songs they love to be included in the set that you would love hear an arrangement of. Happy to do this, always exciting to explore new repertoire.
